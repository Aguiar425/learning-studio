# learning-studio

It's a personal learning project with React, TypeScript, Vite, Vitest, ESLint and Prettier.

Live: https://learning-studio.vercel.app/

## Install and run

```sh
cd learning-studio
npm install
npm run dev
```

## Scripts

| Script                    | What it does                     |
| ------------------------- | -------------------------------- |
| `npm run dev`             | Start the Vite dev server        |
| `npm run build`           | Typecheck, then production build |
| `npm run preview`         | Serve the production build       |
| `npm run typecheck`       | Run the TypeScript compiler      |
| `npm run typecheck:watch` | Typecheck in watch mode          |
| `npm run lint`            | Run ESLint                       |
| `npm test`                | Run tests with Vitest            |
